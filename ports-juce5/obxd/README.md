Obxd
====

* Upstream URL: <https://github.com/reales/OB-Xd>

* License: GPL-3.0-only

  * Some comments in the source code state that the license is GPL-2.0-only;
    however, the upstream project explicitly states that the license is
    GPL-3.0-only, and uses a version of JUCE licensed as such. The source code
    comments originate from the [original version] of Obxd, but even in that
    version, the author included the text of version 3 of the GNU GPL in a file
    called “license.txt”; thus, it is reasonable to assume that was the
    intended license.

    Additionally, the author of the modified version of Obxd present here, who
    explicitly stated that the license is GPL-3.0-only, was given a “private
    use license” by the original author, which allows use in ways not permitted
    by the GNU GPL, such as inclusion in proprietary software. That “private
    use license” may have also been sufficient to relicense the project as
    GPL-3.0-only (required due to the use of a version of JUCE licensed as
    such), should that have been deemed necessary given the potential ambiguity
    of the license of the original.

[original version]: https://github.com/2DaT/Obxd
